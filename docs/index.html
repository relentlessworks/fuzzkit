fuzzkit

Agentic-first fuzzy string matching service

Go MCP Stateless Single Binary Zero Config
View on GitHub API Reference

Quick Start

# Build and run
make build
./fuzzkit -no-auth

# Compute Levenshtein distance
curl 'http://localhost:8427/levenshtein?s1=kitten&s2=sitting'
# distance=3 ratio=0.5714 s1=kitten s2=sitting

# Find best match
curl 'http://localhost:8427/find?q=appel&candidates=apple,orange,banana&algorithm=jaro-winkler'
# match=apple score=0.9333 algorithm=jaro-winkler query=appel

# Get Soundex code
curl 'http://localhost:8427/soundex?s=Robert'
# code=R163 s=Robert

Principles

Agent IS the Interface

No UI, no SDK. The AI agent is the user. The API is the product.

Plain Text by Default

One labeled, grepable line per record. JSON on demand via ?format=json.

Instructive Errors

Every 4xx includes a hint telling the agent what to do next.

Self-Documenting

GET /help returns a one-page operating manual the agent loads at runtime.

Single Static Binary

Go, CGO_ENABLED=0, zero external dependencies. Deploys as one file.

MCP Connector

Speaks Model Context Protocol at POST /mcp for chat client integrations.

API Endpoints

GET /levenshtein?s1=&s2= Levenshtein edit distance
GET /damerau?s1=&s2= Damerau-Levenshtein distance (with transpositions)
GET /hamming?s1=&s2= Hamming distance (equal-length only)
GET /jaro?s1=&s2= Jaro similarity
GET /jaro-winkler?s1=&s2= Jaro-Winkler similarity (prefix-weighted)
GET /ratio?s1=&s2= Difflib-style ratio
GET /sorensen-dice?s1=&s2= Sørensen-Dice coefficient
GET /ngram?s1=&s2=&n=2 N-gram similarity
GET /compare?s1=&s2= All similarity metrics at once
GET /soundex?s= Soundex phonetic code
GET /metaphone?s= Metaphone phonetic code
GET /nysiis?s= NYSIIS phonetic code
GET /find?q=&candidates=a,b,c Best match from list
GET /filter?q=&candidates=a,b,c&threshold=0.7 Filter by similarity threshold
GET /rank?q=&candidates=a,b,c All candidates ranked by score
POST /mcp MCP JSON-RPC 2.0 endpoint (15 tools)
